# System Requirements

## Hardware Requirements (minimum)

OS: Windows 10/11 64-bit

CPU: Quad-core processor

RAM: 8 GB

GPU: Dedicated graphics card with DirectX 12 support

Storage: 1 GB of free disk space

## Software Requirements

- Python **3.13**
- Updated GPU drivers (NVIDIA / AMD)

# How To Play

## User Interfaces

Navigate through UIs with your mouse. Left-click to press the UI buttons.

## Gameplay

### Mouse
- Move Mouse: Aim
- LMB: Shoot

### Controller
- RS/R3: Aim
- RB/R1: Shoot
